## [Unreleased]

### Added

- Live list of TCP and UDP sockets with their owning processes.
- Search, protocol and scope filters, and a switch for Windows' own processes.
- Details panel with path, command line, start time and hosted Windows services.
- Stop a process or its whole process tree, with protection for critical Windows processes.
- System tray icon; closing the window hides it to the tray.
- Restart as administrator from the status bar.
- `portlens` command line tool.
